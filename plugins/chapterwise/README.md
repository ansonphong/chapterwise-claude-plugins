# ChapterWise plugin

The plugin source. Commands live in `commands/`, analysis modules in `modules/`,
Python utilities in `scripts/`, format converters in `patterns/`, reader
templates in `templates/`, and shared reference docs in `references/`.

**Documentation lives at the repository root: [README.md](../../README.md)** —
install, every command with arguments and examples, the Codex format, and the
analysis module catalog. It is kept in one place so the two copies cannot drift.
